# Certificates Library & Digital Shelf Tool

A sleek, lightweight web application designed to showcase professional credentials in an organized, searchable, and filterable "digital shelf" format.

## 🚀 Features
*   **Dynamic Filtering:** Sort certifications by category (Engineering, IT, Design, etc.).
*   **Live Search:** Find specific credentials instantly using the real-time search bar.
*   **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing.
*   **Dark Mode Support:** A built-in theme toggle for comfortable viewing in any lighting.
*   **Interactive Modal:** Click any certificate to view a high-resolution version.
*   **Smooth UX:** Includes a custom-branded loading progress bar on entry.

## 🛠️ Tech Stack
*   **HTML5:** Semantic structure.
*   **CSS3:** Custom properties (CSS variables) for easy skinning and Dark Mode.
*   **JavaScript (Vanilla):** Light-weight logic for filtering and modal interactions.
*   **Font Awesome:** For professional iconography.

## 📂 Repository Structure
*   `index.html` - The core application file.
*   `/assets` - (Optional) Place your certificate images here.
*   `README.md` - Project documentation.
